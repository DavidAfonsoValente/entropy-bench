# Title options

The release uses option 1. It carries the historical story, names the object being evaluated, and
does not reduce the contribution to BPB alone.

1. **Back to Entropy: Evaluating Base Language Models Beyond Perplexity and Benchmarks**
2. **Beyond Perplexity and Benchmarks: A Modern Entropy Protocol for Base Language Models**
3. **Evaluating Base Language Models with Adapted Entropy**
4. **Entropy After Adaptation: A Fair Ruler for Base Language Model Selection**
5. **A Modern Return to Entropy for Base Language Model Evaluation**
6. **One Objective, One Ruler: Comparing Base Language Models on Fresh Target Data**
7. **From Perplexity to Benchmarks and Back: Reliable Entropy Evaluation for Language Models**
8. **Fresh Data, Fair Adaptation, Comparable Entropy: Evaluating Base Language Models**
9. **Measuring Base Models Where They Will Be Used: Target-Domain Entropy After Adaptation**
10. **Entropy Bench: Tokenizer-Agnostic Evaluation of Adaptable Base Language Models**

The central claim is the protocol: fresh evaluator-controlled text, byte-normalized predictive
loss, equal adaptation, contamination-risk screening, and explicit uncertainty. BPB supplies the
common unit but is not presented as the whole contribution.
